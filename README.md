# Chrome Chamber // Prototype

사이버펑크 로봇 도박장 콘셉트의 1:1 턴제 웹게임 프로토타입입니다.

## 현재 구현

- 회색 휴머노이드 상대 로봇과 1인칭 테이블 화면
- 더블배럴 샷건 형태의 경기용 장치
- 빨간 탄 = 실탄 / 검은 탄 = 공포탄
- 매 턴 시작 시 남은 총 탄환 수, 실탄 수, 공포탄 수 공개
- 플레이어 선택: 내 기체에 발사 / 상대 기체에 발사
- 내 기체에 공포탄을 발사하면 추가 턴
- 실탄 피격 시 내구도 1 감소, 내구도 0에서 패배
- 간단한 확률 기반 상대 AI
- 공포탄: `찰칵 → 티잉—` 합성 사운드
- 실탄: `타앙—!` 합성 사운드
- 로봇 피격 스파크, HUD 손상, 화면 흔들림
- iPad/모바일 대응 반응형 UI

사운드는 외부 파일 없이 Web Audio API로 실시간 합성합니다.

## GitHub Pages

`.github/workflows/pages.yml`에 정적 사이트 배포 워크플로를 포함했습니다.

처음 한 번은 저장소의 **Settings → Pages → Build and deployment → Source → GitHub Actions**에서 Pages를 활성화해야 할 수 있습니다. 활성화한 뒤 `main`에 새 커밋이 들어오거나 워크플로를 수동 실행하면 배포됩니다.

예상 주소:

`https://namyamnamyam.github.io/Russian_Rullet_Robot_Game/`

## 조작

- 화면 버튼으로 조준 대상 선택
- 키보드 `1`: 내 기체에 발사
- 키보드 `2`: 상대 기체에 발사

현재 버전은 코어 루프 검증용이라 아이템, 상점, 스토리 이벤트, 다중 NPC는 아직 포함하지 않습니다.
